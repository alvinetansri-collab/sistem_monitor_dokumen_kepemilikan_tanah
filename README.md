1. Tema
Aplikasi monitoring dokumen kepemilikan tanah untuk membantu masyarakat atau perangkat daerah untuk mengelola infromasi bidang tanah secara rinci. Aplikasi berfokus pada pencatatan data pemilik, bidang tanah, dokumen kepemilikan, dan status kelengkapan dokumen
2. Deskripsi Masalah
- Data bidang tanah sulit dicari ketika masih dikelola secara manual
- Informasi pemilik dan bidang tanah dapat tersebar di beberapa dokumen
- Dokumen pendukung kepemilikan sulit dipantau kelengkapannya
- Pengguna membutuhkan riwayat perubahan data kepemilikan
- Sulit mengetahui bagian bidang tanah yang dokumennya belum lengkap
3. Profil target pengguna
Pengguna utama
Perangkat desa dan kelurahan dan petugas administrasi pertanahan
Pengguna mencatat dan mengelola data administrasi bidang tanah di suatu wilayah
4. Manfaat aplikasi
-  Data bidang tanah dapat dicatat secara terstruktur
-  Informasi pemilik dapat ditemukan lebih mudah dan lebih rinci
-  Dokumen kepemilikan dicatat dan dipantau
-  Pengguna dapat mengetahui kelengkapan dokumen bidang tanah dan riwayat perubahan data
5. Fitur inti
- Data pemilik
- Data bidang tanah
- Dokumen kepmilikan
- Monitoring kelengkapan dokumen
- Pencarian dan filter
- Riwayat perubahan
6. Fitur yang tidak dikerjakan
- Menentukan siapa pemilik tanah sah secara hukum dan keaslian sertifikat
- Menyelesaikan sengketa tanah
- Pengukuran dan penentuan batas tanah secara hukum
- Konsultasi hukum
- Penentuan status hukum berdasarkan hanya data aplikasi
- Pendaftaran dan pembuatan sertifikat tanah
7. Kriteria aplikasi dinyatakan berhasil
- Menambahkan data pemilik dan bidang tanah
- Menghubungkan bidang tanah dengan pemilik
- Mengubah dan menghapus data pemilik
- Mencatat status, kelengkapan dokumen, informasi, dan perubahan dokumen kepemilikan
- Menemukan bidang tanah yang dokumennya belum lengkap
- Melihat ringkasan data
- Menjalankan seluruh fungsi CRUD tanpa masalah
